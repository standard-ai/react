# Scripts

Maintenance scripts, not part of the installed package.

| Script | Purpose |
| --- | --- |
| `export_eindhoven_csv.py` | Export a sample of a cached Eindhoven parquet shard to CSV (used to make the bundled 40-track sample and the larger subsets the experiments read from `.data/`) |
| `export_gru_checkpoints.py` | Re-save trained GRU checkpoints as the weights-only files the package ships |
